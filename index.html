路径

路径描述方式 – Linux的上级目录只有一个”/“;而Windows里可以是C盘、D盘等

  1. 与Windows区别
    1. Windows – ...:...\...
    2. Linux – /.../...
  2. 绝对路径与相对路径
    1. 绝对路径:以根目录为起点
    2. 相对路径:以当前目录为起点
  3. 特殊路径符
    1. .表示当前目录
    2. ..表示上一级目录
    3. ~表示HOME目录

命令

Linux命令基础格式

command [-optionns] [parameter]

  1. command为命令本身
  2. -options为命令的一些选项，可以通过选项控制命令的行为细节
  3. parameter为命令的参数，多数用于命令的指向目标等

目录操作

ls命令 – 列出目录下的内容

ls [-a -l -h] [Linux路径]

  1. 不使用选项和参数，ls表示以平铺的形式列出当前工作目录下的内容
  2. 增加[Linux路径]时为以平铺的形式列出此路径下的内容
  3. [-a -l -h] – 可以混合使用
    1. -a – 列出全部文件(包含隐藏的文件/文件夹)，隐藏的会自带.前缀
    2. -l – 以列表的形式展示内容，能够展示更多的信息
    3. -h – 以易于阅读的形式，列出文件的大小(K,M,G)，必须和-l一起使用

cd命令

cd [Linux路径] – Change Directory到指定路径之下，不写参数默认回到用户HOME目录

pwd命令

Print Work Directory – 查看当前的工作目录

mkdir命令

mkdir [-p] Linux路径

  • -p 表示自动创建不存在的父目录，适用于创建连续多层级的目录 – mkdir -p ./itcast/good/666 连续在.(当前目录)创建itcast\good\666等文件夹

文件操作

touch命令

touch Linux路径 – 在该路径下创建文件

cat命令

cat Linux路径 – 查看该路径的文件，直接将内容全部显示出来

more命令

more Linux路径 – 查看该路径的路径，如果文件内容过多，可以一页页的展示，通过按q退出查看

文件或目录操作

cp复制命令

cp [-r] 参数1 参数2

  • -r用于复制文件夹，表示递归，将文件夹内所有文件进行复制
  • 参数1，Linux路径，表示被复制的文件或文件夹
  • 参数2，Linux路径，表示要复制去的地方

mv操作

mv 参数1 参数2

  • 参数1，Linux路径，表示被移动的文件或文件夹
  • 参数2，Linux路径，表示要移动去的地方，如果目标不存在，则进行改名，确保目标存在(将参数2改名成参数3)

rm操作

rm [-r -f] 参数1 参数2...参数N

  • 同cp命令一样，-r用于删除文件夹
  • -f表示force，强制删除，不会弹出提示确认信息
  • 后续的参数表示要删除的文件或文件夹的路径
  • 支持通配符*进行模糊匹配删除，test*表示以test开头的内容，*test表示以test结尾的内容， *test*表示匹配任何包含test的内容

流程函数

  1. IF(value,t,f) – 如果value的值为true，返回t否则返回f
  2. IFNULL(value1,value2) 如果value1不为空，返回value1，否则返回value2
  3. CASE WHEN [val1] THEN [res1]... ELSE[default] END – 如果val的值为ture,返回res1,否则返回default默认值
  4. CASE [expr] WHEN [val1] THEN [res1]... ELSE[default] END – 如果expr的值为val1,返回res1,否则返回default默认值

约束 – 保证数据库中数据的正确、有效性和完整性

  1. NOT NULL – 非空约束:限制该字段的数据不为空
  2. UNIQUE – 唯一约束:保证该字段的所有数据都是唯一、不重复的
  3. PRIMARY KEY – 主键约束:主键是一行数据的唯一标识，要求非空且唯一
  4. DEFAULT '' – 默认约束:保存数据时，如果未指定该字段的值，则采用默认值
  5. CHECK() – 检查约束:保证字段值满足某一个条件
  6. FOREIGN KEY – 外键约束:用来让两张表的数据之间建立连接，保证数据的一致性和完整性
  7. 建表时:

  1. 建表后:
    ALTER TABLE 从表名 ADD CONSTRAINT 外键约束名 FOREIGN KEY(外键字段名) REFERENCES 主表(主表被引用的列名)； – 其中外键字段名为外键在；外键在从表之中，指向主表；外键约束名为规则的标签，用来后续维护规则时指定此规则，为fk_从表_主表。

  2. 删除更新行为 – 在添加约束尾部加上ON UPDATE... ON DELETE...选择更新删除的行为模式
    1. CASCADE – 当在父表中删除/更新记录时，如果该记录有外键连接，则也删除/更新外键在子表中的记录
    2. SET NULL – 当在父表中删除/更新记录时，如果有记录外键连接，将子表对应外键值设置为NULL
    3. NO ACTION/RESTRICT – 有记录外键则不能删除/更新(默认行为)

事务 – 是一组操作的集合，将所有的操作作为一个整体一起向系统提交或撤销操作，要么同时成功，要么同时失败

并发事务问题

  1. 脏读 – 一个事务读到另外一个事务还没有提交的数据(事务A可能被撤销，但事务B读取到这部分的数据，结果A被撤销，B读取的数据此时是错误的)
  2. 不可重复读 – 一个事务先后读取同一条记录，但两次读取的数据不同(被修改了)
  3. 幻读 – 一个事务按照条件查询数据时，没有对应的数据行，但是在插入数据时，又发现这行数据已经存在

事务隔离级别

  1. 事务隔离级别 – 解决的问题

  2. Read uncommitted – 可以读到别人还没提交的数据

  3. Read committed – 脏读 – 只能读到别人已经提交的数据

  4. Repeatable Read(默认) – 不可重复读 – 保证在同一个事务内，多次读取同一行数据的结果是一样的

  5. Serializable – 幻读 – 所有事务排队执行，完全不会冲突，但效率最低

  6. 查看事务隔离级别
    SELECT @@ TRANSACTION_ISOLATION;

  7. 设置事务隔离级别
    SET [SESSION | GLOBAL] TRANSACTION ISOLATION LEVEL {READ UNCOMMITTED | READ COMMITTED | REPEATABLE READ | SERIALIZABLE}

  8. 使用方法

START TRANSACATION; -- 开启事务
... -- 步骤1
... -- 步骤2
... -- 步骤...
COMMIT; -- 如果上述操作都成功，提交事务，永久保存
``` -- 如果期间发生任何错误 撤销所有操作

DML语句(字段)、DQL语句(查询)

DML语句 – 对数据库中表的数据记录进行增删改操作

插入数据操作 – 值是字符串或日期型数据需要包含在单引号之中

  1. INSERT INTO 表名 (字段1,字段2...) VALUES (值1,值2...); – 给指定字段添加数据
  2. INSER INTO 表名 VALUES (值1,值2...); – 给全部字段添加数据
  3. INSERT INTO 表名 VALUES (值1,值2...),(值1,值2...),(值1,值2...); – 给指定表批量添加数据

更新数据操作

  1. UPDATE 表名 SET 字段名1 = 值1,字段名2 = 值2,...[WHERE 条件] – 修改数据，如果没有条件，则会修改整张表的所有数据

删除数据操作

  1. DELETE FROM 表名 [WHERE 条件] – 删除数据，没有WHERE条件则会删除整个表的数据，且不能删除某一个字段的值(可以使用UPDATE)

DQL语句 – 用来查询数据库中表的记录

代码模板 – 编写顺序！！！

基本查询

  1. SELECT 字段1,字段2,字段3... FROM 表名; – 查询多个字段
  2. SELECT 字段1 [AS 别名1], 字段2 [AS 别名2] ... FROM 表名; – 设置别名
  3. SELECT DISTINGCT 字段列表 FROM 表名; – 去除重复记录

条件查询

  1. SELECT 字段列表 FROM 表名 WHERE 条件列表
  2. 常见条件

    1. – 大于

    2. = – 大于等于

    3. < – 小于
    4. <= – 小于等于
    5. <>或!= – 不等于
    6. BETWEEN … AND … – 在某个范围之内(包含边界值)
    7. IN(…) – 值在IN之内的符合某一个就行
    8. LIKE 占位符 – 模糊匹配(_匹配单个字符，%匹配任意个字符，比如__代表查找长度为二的字符数据，%x代表以x结尾的数据)
    9. IS NULL – 是NULL
    10. AND或&& – 并且
    11. OR或|| – 或者
    12. NOT或! – 非、不是

聚合函数查询 – 偏计算

  1. 聚合函数 – 将一列数据作为一个整体，进行纵向计算(所有的NULL值不参与计算)
    1. count – 统计数量
    2. max – 最大值
    3. min – 最小值
    4. avg – 平均值
    5. sum – 求和
  2. SELECT 聚合函数(字段列表) FROM 表名; – 根据函数查找数据

分组查询

  1. SELECT 字段列表 FROM 表名 [WHERE 条件] GROUP BY 分组字段名 [HAVING 分组后的过滤条件]; – WHERE在分组之前进行过滤，不满足WHERE条件则不参与分组；而HAVING是分组之后对结果进行过滤
    1. SELECT gender, count(*) FROM employee GROUP BY gender – 根据性别分组，统计男性员工和女性员工的数量
    2. SELECT worKaddress,count(*) FROM emp WHERE age < 45 GROUP BY workaddress HAVING count(*)>=3; – 查询年龄小于45的员工，并根据工作地址分组，获取员工数量大于等于3的工作地址
  2. 执行顺序
    WHERE > 聚合函数 > HAVING

排序查询

  1. SELECCT 字段列表 FROM 表名 ORDER BY 字段1 排序方式1, 字段2 排序方式2; – 如果是多字段排序，当第一个字段值相同时，才会根据第二个字段进行排序
  2. 排序方式
    1. ASC – 升序(默认)
    2. DECE – 降序

分页查询

  1. SELECT 字段列表 FROM 表名 LIMIT 起始索引,需要查询个数; – 浏览器中的第几页的这一整页的数据依此在数据库中查询，或者说从第几个查询到第几个
  2. tips
    1. 起始索引从0开始，起始索引=(查询页码数-1)*每页显示记录数
    2. 分页查询是数据库的方言，不同的数据库有不同的实现，MySQL中是LIMIT
    3. 如果查询的是第一页数据，起始索引可以省略，直接简写为LIMIT 10

DQL的执行顺序 – 了解就好，在简写as之中需要知道

FROM从哪个表查询 -> WHERE选取表中的哪些数据 -> GROUP BY进行分组查询 -> SELECT选取需要展示的字段 -> ORDER BY进行顺序的排序 -> LIMIT分页显示个数

SQL相关概述、DDL语句(库、表)

SQL相关概述

  1. 数据库：数据存储的仓库。
  2. 数据库管理系统：操纵和管理数据库的大型软件。
  3. SQL：操作关系型数据库的编程语言，为统一标准。

SQL通用语法

  1. SQL语句可以单行或多行书写，以分号结尾。
  2. SQL语句不区分大小写，关键字建议大写。
  3. 单行注释为“–”或“#”，多行注释为“/**/” 。

SQL语句分(Data Definition/Manipulation/Query/Control language)

  1. DDL数据定义语言，用来定义数据库对象(数据库、表、字段)。
  2. DML数据操作语言，用来对数据库中的数据进行增删改。
  3. DQL数据查询语言，用来查询数据库中表的记录。
  4. DCL数据控制语言，用来创建数据库用户、控制数据库的访问权限。

DDL语句(库操作)

查询

  1. SHOW DATABASES; – 查询所有数据库
  2. SELECT DATABASE(); – 查询当前数据库

创建

  1. CREATE DATABASE[IF NOT EXISTS] 数据库名 [DEFAULT CHARSER 字符集] [COLLATE排列规则]; – 创建新的数据库

删除

  1. DROP DATABASE[IF EXISTS] 数据库名; – 删除数据库

使用

  1. USE 数据库名; – 使用数据库

DDL语句(表操作)

查询

  1. SHOW TABLES; – 查询当前数据库所有表格
  2. DESC 表名; – 查询表结构
  3. SHOW CREATE TABLE 表名; – 查询指定表的建表语句

创建

1.

– 创建表结构(最后一个字段不需要分号，外层需要)

修改

  1. ALTER TABLE 表名 ADD 字段名 类型(长度) [COMMENT注释][约束]; – 对表添加字段
  2. ALTER TABLE 表名 MODIFY 字段名 新数据类型(长度); – 修改数据类型
  3. ALTER TABLE 表名 CHANGE 旧字段名 新字段名 类型(长度) [COMMENT 注释][约束]; – 修改字段名和字段类型
  4. ALTER TABLE 表名 RENAME TO 新表名; – 修改表的名称

删除

  1. ALTER TABLE 表名 DROP 字段名; – 删除字段
  2. DROP TABLE [IF EXISTS] 表名; – 删除表
  3. TRUNCATE TABLE 表名; – 删除指定表，并重新创建该表

二进制数据(音频、图片…)

文本数据

  2. TEXT

  4. LONGTEXT

日期类型

堆

满足特定条件的完全二叉树，可分为小顶堆(任意节点的值<=子节点的值)和大顶堆(任意节点的值>=子节点的值)。根节点称为堆顶，底层最靠右的为堆低。大顶堆的堆顶元素最大，小顶堆的堆顶值最小。

堆通常用于实现优先队列，即具有优先级排序的队列。

数据结构

二叉树、AVL树

结构体构造函数

一般先使用malloc动态分布一个结构体外壳，然后对内部数据进行初始化。

二叉树的分类

  1. 完美二叉树：所有层的节点都被完全填满，也被称为满二叉树。
  2. 完全二叉树：仅允许最底层的节点不完全填满，且最底层的节点必须从左至右依次连续填充。
  3. 完满二叉树：除了叶节点之外，每个节点都有两个子节点。
  4. 平衡二叉树：任意节点的左子树和右子树的高度之差的绝对值不超过1。

二叉树的遍历方式

  1. 层序遍历：根左右根左右，类广度优先搜索，通常使用队列实现。
  2. 前序遍历、中序遍历、后序遍历：绕着二叉树的外围走一圈，类深度优先搜索。根据走到一个节点的访问时的位置分为前中后，左边是前，下面是中，右边是后。根左右、左根右、左右根。

二叉树的实现形式

通过链表存储，节点之间通过指针连接；通过数组存储的时候，如果不是完美二叉树，则数组无法唯一表示二叉树，可以考虑在遍历中显式地写出所有的None，如用INT_MAX代替。

相比之下数组表示的优点在于其存储在连续的内存空间中，对缓存友好，访问与遍历速度较快；不需要存储指针，节省空间；可以通过rand()函数随机访问节点。

数组表示的缺点在于增删节点需要通过数组插入与删除操作实现，效率低；当二叉树存在大量None的时候，内存利用率低；同时因为其存储于连续的空间之中，也不适用于存储数据量过大的树。

二叉搜索树

原理

其值按照左根右的顺序增大，因此可以按照值的大小关系进行查找。查找原理与二分查找算法一致。如可以使用cur表临时节点，cur.val < num代表目标节点在cur的右子树之中，执行cur=cur.right。

增加

二叉搜索树只要满足于左右根的递增就可以，新增加的元素永远在最底层，在cur.val比较的时候小于往左跑，大于往右跑，直到遇到NULL替代掉。

删除

二叉搜索树的中序遍历出来的数据是按照从小到大的顺序排列的。删除时如果度为0直接删；度为1直接用叶节点替换掉；度为2的时候可以选择二叉搜索树中序遍历里这个删除节点左右的任意一个值，删掉后替换到这个位置。

描述

对于类深度优先搜索，根的代码一般为arr[(*size)++] = root->val；左的代码为Order(root->left, size)；右的代码为Order(root->right, size)。三种遍历的区别在于这三个的相对位置的不同。

AVL树

产生原因

平衡二叉树增删后可能变成一条“/”，退化成链表，AVL树可以通过旋转操作，使其能够保持二叉搜索树的性质，也能重新变成平衡二叉树

核心要素

节点高度：从该节点到最远叶节点的距离，即所经过的边的数量叶节点的高度为0，空节点高度为-1；

节点平衡因子：节点左子树高度减去右子树高度，空节点的平衡因子为0。

旋转

从下到上第一个失衡节点记为node，其子节点记为child。将中间平衡的节点提拔成新的当家的，失衡的节点压下去。

  1. 左旋：失衡节点右边成一条斜线“\”，node变成child的左节点(如果原本有左节点，将之变为node右节点)，child代替node的位置。
  2. 右旋：失衡节点左边成一条斜线“/”，node变成chlid的右节点(如果原本有右节点，将之变为node左节点)，child代替node的位置。
  3. 先左旋再右旋：向左突出来的拐角“<”，对child左旋，变成一条斜线“/”，然后进行右旋。
  4. 先右旋再左旋：向右突出来的拐角“>”，对child右旋，变成一条斜线“\”，然后进行左旋。

AVL树

  1. 插入元素：循环递归至最下面的NULL区域添加，同时返回时自底向上更新节点高度，执行旋转操作
  2. 删除元素：依旧循环自底向上更新节点高度，执行旋转操作。
  3. 旋转操作避免退化成链表。
  4. 叶子节点高度为0，空节点高度为-1。
  5. 节点平衡因子由左子树高度减去右子树高度。

树相关概念

二叉树 || 二叉搜索树 || AVL树

因实现方式的选择差异(链表、数组)，导致在遍历或增删查改的操作会有差异

AVL树的旋转场景(大佐小右)

节点平衡因子大于1(左子树偏高)

  1. 左子节点节点平衡因子大于等于0->单次右旋
  2. 左子节点节点平衡因子小于0->先左旋再右旋

节点平衡因子小于-1(右子树偏高)

  1. 右子节点节点平衡因子小于等于0->单次左旋
  2. 右子节点节点平衡因子大于0->先右旋再左旋
