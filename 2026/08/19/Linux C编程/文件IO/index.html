文件IO

系统IO VS 标准IO

  1. 系统IO，包含open、read…，每次调用都需要从用户态转换成内核态，while多次循环性能消耗大，实时性更高，不用等待缓冲区填满
  2. 标准IO，包含fopen、read…，调用时会开辟一块内存(用户Buffer)，while多次循环满了或者调用结束时一次性返回。但底层还是使用系统IO，只是多了一个用户Buffer

综合来说标准IO适合普通磁盘文件、日志、配置文件的读写，追求批量处理的高吞吐量与便捷性；而系统IO适合硬件驱动、网络Socket、并发控制、实时响应等，追求绝对控制与实时性

main函数的另类写法

int main(int argc, char** argv)当终端运行命令如./test1 1.txt，argc会接收传入的参数个数(./test1和1.txt两个)，argv则接收参数，此时argv[0]为./test1，argv[1]为1.txt(二者都是string字符数组，故类型为char**)

open简略语法(打开/创建)

int open(const char* path, int flags, *mode_t mode*)path为文件路径字符串；flags为打开模式O_RDONLY只读、O_WRONLY只写、O_RDWR可读可写；如果flags为O_RDWR | O_CREAT即包含O_CREAT，代表不存在就新建，mode_t mode用来指定新文件的权限

例：int fd = open("new_file.txt, O_RDWR | O_CREAT, 0664);

注意事项：

  1. 如果文件的权限和flags指定的打开权限不一致会报错
  2. 需要头文件<sys/types.h>、<sys/stat.h>、<fcntl.h>，可用man手册查询
  3. flags可以是…|…|…
  4. *mode_t mode*只有在创建新文件时才起效果，格式为0***
  5. 返回值为文件描述符(书签)

read读取

... = read(int fd, void\* buf, size_t count)fd为指定要读写的文件描述符；buf缓冲区，用于存放读取的内容；count为一次要读取的最大字节数

注意事项：

  1. 需包含头文件<unistd.h>
  2. read返回值为实际读取的字节数
  3. read读取的buf数据不会有字符串结束符”\0”，因为数据可以是图片、文本、音频等格式，可以是二进制数据，也可以是字符串数据。故需要以字符串格式打印时需要手动增加结束符

write写入

... = write(int fd, const void* buf, size_t count);fd为写入的目标，可以是open返回的普通文件，也可以是标准输出设备(1或STDOUT_FILENO)…；buf为写入数据源内存空间指针；count写入的字节数

例：ssize_t bytes_written = write(STDOUT_FILENO, msg, strlen(msg))

注意事项：

  1. 需包含头文件<unistd.h>
  2. write返回值为实际写入的字节数，可能小于count(磁盘空间不足、中断、管道满了等)

dup函数

int 新的文件描述符 = dup(旧的文件描述符)

注意事项：

  1. 需包含头文件<unistd.h>
  2. 此后新的文件描述符和旧的文件描述符共享一个file结构体(书签)

close函数

int close(int fd);用来关闭已打开的设备文件并释放文件描述符，成功返回0，失败返回-1

lseek(文件偏移量)

off_t lseek(int fd, off_t offset, int whence);fd为文件描述符；offset为移动的字节数，正数向文件尾部移动，负数向文件头部移动；whence为基准位置，设定从哪里开始计算偏移，有三个固定选项：SEEK_SET文件头部，SEEK_CUR当前位置，SEEK_END文件末尾

注意事项：

  1. 需包含头文件<sys/types.h>和<unistd.h>
  2. 成功返回移动后光标距离文件头部的绝对字节数，类型为off_t通常是个长整型，失败则返回-1
  3. 普通文件、块设备文件支持lseek，管道、套接字、串口等流式设备不支持lseek
  4. 常用于获取文件总大小(光标移动末尾，返回文件总字节数)、获取当前光标所在位置(SEEK_CUR偏移0)

报错处理

返回值与errno

Linux系统函数发生错误时，绝大多数系统调用失败时会返回一个特定的标识(通常是-1或NULL)；同时系统会自动设置一个名为errno的全局变量，出错时会对其赋值对应错误整数(不及时处理会被覆盖)。使用errno需要包含头文件<error.h>

报错函数perror()

涉及于头文件<stdio.h>，perror会自动读取当前error值，并翻译成英文错误描述，打印格式为：自定义提示信息：系统内置错误描述，如perror("打开文件夹失败")会在终端中显示打开文件失败：No such file or directory。单纯使用perror不需要<error.h>头文件

ioctl(Input Output Control输入输出控制)

用于应用程序对硬件设备改配置、查状态等操作的系统调用，如修改串口波特率、查询显示屏分辨率等

int ioctl(int fd, unsigned long request, ...)fd文件描述符；request控制命令码(驱动预先定义号的宏)；…位数据的地址，如果需要设备返回信息或传配置给设备，传入变量或结构体的内存地址
