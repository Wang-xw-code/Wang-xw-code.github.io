Framebuffer、点阵显示

Created2026-08-23|Updated2026-08-25|Linux C编程
|Post Views:

Framebuffer

概念明晰

是Linux内核提供的一种显卡驱动接口，将在内存中映射的屏幕上显示的图像数据抽象成一个可以被直接读写的块设备文件(通常为/dev/fb0)。屏幕上的每个像素点都对应内存中一块连续的字节

标准编程步骤

  1. 打开设备文件
  1. 获取屏幕信息，通过ioctl系统调用获取内核传入的屏幕参数(常用结构体fb_var_screeninfo)

其中bits_per_pixel(bpp)为每个像素占多少位，常用32位，即ARGB8888

  1. 内存映射，计算屏幕总字节大小，并将其映射到用户空间

screensize的计算中vinfo.xres和vinfo.yres代表横纵向分辨率(即横纵方向上的像素点个数)，vinfo.bits_per_pixel为位深，即控制一个像素点的颜色需要多少个二进制位(bit)，常见位深有RGB565、RGB888、ARGB8888

  1. 画点算法，在指定坐标处绘制指定颜色
  1. 资源清理，取消映射并关闭FD

相关系统调用函数

mmap(内存映射)

void *mmap(void *addr, size_t length, int prot, int flags, int fd, off_t offset);

  1. addr：映射的起始地址，通常填NULL，让系统自动帮你找一块合适的内存。
  2. length：要映射的内存大小（字节数，即屏幕总像素点数 * 每一个像素占用的字节数）。
  3. prot：映射区域的保护权限。如 PROT_READ | PROT_WRITE（可读可写）。
  4. flags：标志位。一般用 MAP_SHARED（修改内容对其他进程和硬件直接生效）。
  5. fd：被映射的文件描述符（即 open 打开 /dev/fb0 返回的 fd）。
  6. offset：映射文件的偏移量，通常从头开始，填 0

munmap(取消内存映射)

int munmap(void *addr, size_t length);

  1. mmap 返回的内存首地址
  2. 之前映射的内存长度

ioctl(获取屏幕参数)

ioctl(fd, FBIOGET_VSCREENINFO, &vinfo);

  1. fd：/dev/fb0 的文件描述符。
  2. FBIOGET_VSCREENINFO：这是一个预定义的命令宏，意思是“获取屏幕的可变参数（如分辨率、色深等）”。
  3. &vinfo：传入一个结构体指针，ioctl 执行完后，系统会把屏幕的宽、高、位深等信息填进这个结构体里。

背景
