线程处理

线程创建

int pthread_creat(pthreadd_t* thread, const pthread_attr_t* attr, void* (*start_routine)(void*), void* arg);

  1. pthread_t* thread指向线程标识符的指针，线程创建成功时，用于存储新创建线程的线程标识符
  2. const pthread_attr_t* attr为pthead_attr_t结构体，可以设置线程的属性，如优先级、栈大小等，如不需指定可传入NULL采用默认属性
  3. void* (*start_routine)(void*)为指向函数的指针，定义了线程开始执行时的入口点，这个函数必须接收一个void*类型的参数，并返回void*类型的结果
  4. void* arg为start_routine函数的参数，可以是一个指向任意类型数据的指针
  5. 成果返回0，失败返回-1

线程终止

必要性

如果线程终止后没有调用pthread_detach或pthread_join，其资源会继续占用内存，类似于僵尸进程的未回收状态。默认情况下创建线程后，线程处于可join状态，此时可以调用pthread_join等待进程终止并回收资源。如果不需要等待终止，可标记为detach状态，意味线程终止后其资源会被系统自动回收

终止途径

  1. 线程函数执行return语句
  2. 线程函数内部调用pthread_exit函数
  3. 其他线程调用pthread_cancel函数

函数示例

  1. void pthread_exit(void* retval);

当某个线程调用pthread_exit方法后，该线程会被关闭。线程可以通过retval向其他线程传递信息，retval指向的区域不可放在线程函数栈内。其他线程若要获取该返回值，需调用pthread_join方法

  1. int pthread_join(pthread_t thread, void** retval);

    1. pthread_t thread为指定线程ID
    2. void** retval为可选参数，用于接收线程结束后传递的返回值，如果非空pthread_join会在成功时将线程的exit status复制到*retval所指向的内存位置。如果线程没有显式通过pthread_exit提供返回值，该参数将被设置为NULL
    3. 成功返回0，失败返回-1
    4. 调用后会阻塞等待到所指定的线程ID结束

  2. int pthread_detach(pthread_t thread);

    1. pthread_t thread为线程ID
    2. 成功返回0，失败返回错误码

  3. int pthread_cancel(pthread_t thread);
