信号量

分类

  1. 按逻辑功能划分
    1. 计数信号量：控制多件同类资源的并发访问(最大并发线程数)
    2. 二值信号量：一次只允许一个进程/线程访问
  2. 按物理存在形式划分
    1. 有名信号量：存在于虚拟文件系统中(Linux下挂载在/dev/shm/sem.xxx)，支持无亲缘关系的任意进程间同步
    2. 无名信号量：位于进程分配的内存空间中(堆、全局变量区或共享内存)，默认仅用于同一进程的多线程，随进程结束

辨析

二值信号量与互斥锁

互斥锁谁加锁，必须由谁解锁，只能管理一个资源；信号量任何人都可以发信号(强调跨线程协同)，可以管理一个或N个资源

相关API

无名信号量

初始化sem_init

int sem_init(sem_t* sem, int pshared, unsigned int value);

  1. sem为sem_t的结构体指针变量(自定义)
  2. pshared为0用于同一进程内的多线程同步，应该至于所有线程均可见的地址；非0用于进程间同步，应该被置于共享内存区域，任何进程只要能访问共享内存区域，即可操作进程间共享的信号量
  3. value为信号量的初始(计数)值

销毁sem_destory

int sem_destory(sem_t* sem);

销毁前不得有任何线程正在阻塞等待该信号量

有名信号量

创建sem_open

sem_t* sem_open(const char* name, int oflag, mode_t mode, unsigned int value);

  1. name必须以/开头的名字
  2. oflag可选O_CREAT或O_EXCL等
  3. mode为创建的权限位
  4. value为创建时的初始值

关闭sem_close

int sem_close(sem_t* sem);

关闭当前进程内的句柄，并不销毁内核资源

解链接sem_unlink

int sem_unlink(const char* name;

从文件系统中抹除名称，当最后一个引用关闭时彻底解放

P/V操作

阻塞P操作sem_wait -P操作

int sem_wait(sem_t* sem);

尝试将信号量减1，若计数值小于等于0，当前线程立即被挂起休眠，直到获得资源或被信号中断返回EINTR

非阻塞试探P操作sem_trywait -P操作

int sem_trywait(sem_t* sem);

若信号量大于0，减1并返回，若信号量等于0，立刻返回-1，并设置errno值

绝对超时控制P操作sem_timedwait -P操作

int sem_timedwait(sem_t* restrict sem, const struct timespec* restrict abstime);

abstime传入绝对时间

释放资源sem_post -V操作

int sem_post(sem_t* sem);

将信号量加1，并在必要时唤醒挂起队列中的一个线程，该函数时信号安全的，可以在UNIX信号处理函数中安全调用
