数据库

函数

函数 – 前加select为了获取并显示该函数的运行结果

字符串函数

  1. CONCAT(S1,S2,S3...) – 字符串拼接
  2. LOWER(S1) – 将字符串转为小写
  3. UPPER(S1) – 将字符串转为大写
  4. LPAD(S1,n,pad) – 左填充，用字符串pad对S1左边进行填充，达到n个字符串长度
  5. RPAD(S1,n,pad) – 右填充，用字符串pad对S1右边进行填充，达到n个字符串长度
  6. TRIM(S1) – 去掉字符串头部和尾部的空格
  7. SUBSTRING(S1,start,len) – 返回从字符串S1从start位置起的len个长度的字符串

数值函数

  1. CEIL(X) – 向上取整
  2. FLOOR(X) – 向下取整
  3. MOD(x,y) – 返回x/y的值
  4. RAND() – 返回0-1内的随机数
  5. ROUND(x,y) – 求参数x的四舍五入的值，保留位小数

日期函数

  1. CURDATA() – 返回当前日期
  2. CURTIME() – 返回当前时间
  3. NOW() – 返回当前的日期和时间
  4. YEAR(date) – 获取指定date的年份
  5. MONTH(date) – 获取指定date的月份
  6. DAY(date) – 获取指定data的日期
  7. DATE_ADD(date, INTERVAL expr type) – 返回一个日期/时间值加上一个时间间隔expr后的值
  8. DATEDIFF(date1,date2) – 返回起始时间和结束时间之间的天数

流程函数

  1. IF(value,t,f) – 如果value的值为true，返回t否则返回f
  2. IFNULL(value1,value2) 如果value1不为空，返回value1，否则返回value2
  3. CASE WHEN [val1] THEN [res1]... ELSE[default] END – 如果val的值为ture,返回res1,否则返回default默认值
  4. CASE [expr] WHEN [val1] THEN [res1]... ELSE[default] END – 如果expr的值为val1,返回res1,否则返回default默认值

约束 – 保证数据库中数据的正确、有效性和完整性

  1. NOT NULL – 非空约束:限制该字段的数据不为空
  2. UNIQUE – 唯一约束:保证该字段的所有数据都是唯一、不重复的
  3. PRIMARY KEY – 主键约束:主键是一行数据的唯一标识，要求非空且唯一
  4. DEFAULT '' – 默认约束:保存数据时，如果未指定该字段的值，则采用默认值
  5. CHECK() – 检查约束:保证字段值满足某一个条件
  6. FOREIGN KEY – 外键约束:用来让两张表的数据之间建立连接，保证数据的一致性和完整性
  7. 建表时:

  1. 建表后:
    ALTER TABLE 从表名 ADD CONSTRAINT 外键约束名 FOREIGN KEY(外键字段名) REFERENCES 主表(主表被引用的列名)； – 其中外键字段名为外键在；外键在从表之中，指向主表；外键约束名为规则的标签，用来后续维护规则时指定此规则，为fk_从表_主表。

  2. 删除更新行为 – 在添加约束尾部加上ON UPDATE... ON DELETE...选择更新删除的行为模式
    1. CASCADE – 当在父表中删除/更新记录时，如果该记录有外键连接，则也删除/更新外键在子表中的记录
    2. SET NULL – 当在父表中删除/更新记录时，如果有记录外键连接，将子表对应外键值设置为NULL
    3. NO ACTION/RESTRICT – 有记录外键则不能删除/更新(默认行为)

多表查询

多表关系

  1. 一对一 – 在任意一方加入外键，关联另一方的主键，并设置外键为唯一的
  2. 一对多/多对一 – 在多的一方建立外键，指向一的一方的主键
  3. 多对多 – 通过建立第三张中间表，至少包含两个外键，分别关联两个逐渐

多表查询 – 内连接、外连接、自连接(需要通过外键查询)

  1. 分类

  2. 内连接:查询A,B交集部分的数据

  3. 外连接
    1. 左外连接:查询左表的所有数据，以及两张表交集的部分数据
    2. 右外连接:查询右表的所有数据，以及两张表交集的部分数据
    3. 自连接:当前表与自身的连接查询，自连接必须使用表别名

  4. 内连接:
    SELECT ... FROM 表1,表2... where 符合的条件 – SELECT * FROM emp,dept WHERE emp.dept_id = dept.id; – 表头与数据之间的逻辑关系用”.”连接，如emp.dept_id

  5. 左外连接:
    SELECT 字段列表 FROM 表1 LEFT JOIN 表2 ON 条件;

  6. 右外连接:
    SELECT 字段列表 FROM 表1 RIGHT JOIN 表2 ON 条件:

  7. 自连接:
    SELECT 字段列表 FROM 表A 别名A JOIN 表A 别名B ON 条件: – 内连接(交集部分)

SELECT 字段列表 FROM 表A 别名A,表A 别名B WHERE 条件: – 外连接(包含交集之外的部分)

子查询 – SQL语句中嵌套SELECT语句

  1. SELECT * FROM t1 WHERE column1 = (SELECT column1 FROM t2); – 实例，外部可以时INSERT/UPDATE/DELETE/SELECT的任何一个
  2. 分类
  3. 标量子查询 – 子查询结果为单一常值
    1. 常用操作符:=、<>、>、>=、<、<=
  4. 列子查询 – 子查询结果为一列
    1. IN – 在指定的集合范围之内，多选一
    2. NOT IN – 不在指定的集合范围之内
    3. ANY – 子查询返回列表中，有任意一个满足即可
    4. SOME – 与ANY等同，使用SOME的地方都可以使用ANY
    5. ALL – 子查询返回列表的所有值都必须满足
  5. 行子查询 – 子查询结果为一行
    1. 常用操作符:=、<>、IN、NOT IN
  6. 表子查询 – 子查询结果为多行多列
    1. 常用的操作符:IN

事务 – 是一组操作的集合，将所有的操作作为一个整体一起向系统提交或撤销操作，要么同时成功，要么同时失败

并发事务问题

  1. 脏读 – 一个事务读到另外一个事务还没有提交的数据(事务A可能被撤销，但事务B读取到这部分的数据，结果A被撤销，B读取的数据此时是错误的)
  2. 不可重复读 – 一个事务先后读取同一条记录，但两次读取的数据不同(被修改了)
  3. 幻读 – 一个事务按照条件查询数据时，没有对应的数据行，但是在插入数据时，又发现这行数据已经存在

事务隔离级别

  1. 事务隔离级别 – 解决的问题

  2. Read uncommitted – 可以读到别人还没提交的数据

  3. Read committed – 脏读 – 只能读到别人已经提交的数据

  4. Repeatable Read(默认) – 不可重复读 – 保证在同一个事务内，多次读取同一行数据的结果是一样的

  5. Serializable – 幻读 – 所有事务排队执行，完全不会冲突，但效率最低

  6. 查看事务隔离级别
    SELECT @@ TRANSACTION_ISOLATION;

  7. 设置事务隔离级别
    SET [SESSION | GLOBAL] TRANSACTION ISOLATION LEVEL {READ UNCOMMITTED | READ COMMITTED | REPEATABLE READ | SERIALIZABLE}

  8. 使用方法

START TRANSACATION; -- 开启事务
... -- 步骤1
... -- 步骤2
... -- 步骤...
COMMIT; -- 如果上述操作都成功，提交事务，永久保存
``` -- 如果期间发生任何错误 撤销所有操作
