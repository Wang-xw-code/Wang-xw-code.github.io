各类实用小技巧

ctrl + c – 强制停止

可以强制停止某些程序的运行或命令输入错误时退出当前命令行，进入新的命令行(避免一个个的回退删除)

ctrl + d – 强制退出

可退出当前账户的登录，类似于用户操作中的exit；或者退出类似python等程序，vi/vim不可用此命令

history – 查看操作历史

查看历史输入过的命令，同时可结合grep进行历史操作的过滤

！命令前缀 – 重复历史操作

自动执行上一次匹配前缀的命令操作，如!Py可以匹配Python命令(如果最后以Py开头的命令是Python)

ctrl + r – 历史命令搜索

ctrl + r执行完后输入内容去匹配第一个历史命令，此时回车键可直接执行，键盘左右键可直接在此命令上进行修改(修改或其他操作)

光标移动快捷键

  1. ctrl + a/home – 跳到命令开头
  2. ctrl + e/end – 跳到命令结尾
  3. ctrl + 键盘左键 – 向左跳一个单词
  4. ctrl + 键盘右键 – 向右跳一个单词

清屏操作

ctrl + l/clear – 清除终端内容

软件安装

apt [-y] [install | remove | search] 软件名称

  1. -y表示自动确认，无需手动确认安装或卸载过程
  2. install：安装
  3. remove：卸载
  4. search：搜索

systemctl命令 – Linux系统很多软件(内置或第三方)均支持使用systemctl命令控制：启动、停止、开机自启等

systemctl start | start | stop | status | enable | disable 软件名

  • start – 启动
  • stop – 关闭
  • status – 查看状态
  • enbale – 开启开机自启
  • disable – 关闭开机自启

软连接 – 可以将文件、文件夹链接到其他位置，类似Windows系统中的快捷方式

ln -s 参数1 参数2

  • -s – 创建软连接
  • 参数1 – 被链接的文件或文件夹的地址
  • 参数2 – 要连接去的目的地的地址

ip地址与主机名

ip地址

通过ifconfig命令查看本机的ip地址

主机名

  1. 通过hostname查看
  2. 通过hostnamestl set-hostname 主机名修改主机名，但需要root权限

Linux系统管理：root用户、用户与用户组、权限控制
root用户 – 超级管理员 root用户介绍:root用户拥有最大的系统操作权限(在根目录下创建文件夹)；普通用户的权限，一般在其HOME目录内是不受限的，一旦出了HOME目录，大多数地方普通用户仅有只读和执行权限，无修改权限 权限切换: su(Switch User)与exit命令 su [-] [用户名] -符号是可选的，表示是否在切换用户后加载环境变量，建议带上； 用户名省略表示切换到root用户，通过exit命令可退回上一个用户或快捷键control + d； 使用普通用户切换到其他用户需要输入密码，而root用户切换到其他用户无需密码，可直接切换； 临时赋予权限: sudo 其他命令 在其他命令之前带上sudo即可为这一条命令赋予临时的root权限; 但并不是所有的用户都有权力使用sudo，需要为普通用户配置sudo认证; 为普通用户配置sudo认证 切换到root用户，执行visudo命令(会自动通过vi编辑器打开/elc/sudoers)，在文件的最后添加(用户名 ALL=(ALL) NOPASSWD:...
