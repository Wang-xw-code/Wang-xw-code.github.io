数据库

SQL相关概述、DDL语句(库、表)

SQL相关概述

  1. 数据库：数据存储的仓库。
  2. 数据库管理系统：操纵和管理数据库的大型软件。
  3. SQL：操作关系型数据库的编程语言，为统一标准。

SQL通用语法

  1. SQL语句可以单行或多行书写，以分号结尾。
  2. SQL语句不区分大小写，关键字建议大写。
  3. 单行注释为“–”或“#”，多行注释为“/**/” 。

SQL语句分(Data Definition/Manipulation/Query/Control language)

  1. DDL数据定义语言，用来定义数据库对象(数据库、表、字段)。
  2. DML数据操作语言，用来对数据库中的数据进行增删改。
  3. DQL数据查询语言，用来查询数据库中表的记录。
  4. DCL数据控制语言，用来创建数据库用户、控制数据库的访问权限。

DDL语句(库操作)

查询

  1. SHOW DATABASES; – 查询所有数据库
  2. SELECT DATABASE(); – 查询当前数据库

创建

  1. CREATE DATABASE[IF NOT EXISTS] 数据库名 [DEFAULT CHARSER 字符集] [COLLATE排列规则]; – 创建新的数据库

删除

  1. DROP DATABASE[IF EXISTS] 数据库名; – 删除数据库

使用

  1. USE 数据库名; – 使用数据库

DDL语句(表操作)

查询

  1. SHOW TABLES; – 查询当前数据库所有表格
  2. DESC 表名; – 查询表结构
  3. SHOW CREATE TABLE 表名; – 查询指定表的建表语句

创建

1.

– 创建表结构(最后一个字段不需要分号，外层需要)

修改

  1. ALTER TABLE 表名 ADD 字段名 类型(长度) [COMMENT注释][约束]; – 对表添加字段
  2. ALTER TABLE 表名 MODIFY 字段名 新数据类型(长度); – 修改数据类型
  3. ALTER TABLE 表名 CHANGE 旧字段名 新字段名 类型(长度) [COMMENT 注释][约束]; – 修改字段名和字段类型
  4. ALTER TABLE 表名 RENAME TO 新表名; – 修改表的名称

删除

  1. ALTER TABLE 表名 DROP 字段名; – 删除字段
  2. DROP TABLE [IF EXISTS] 表名; – 删除表
  3. TRUNCATE TABLE 表名; – 删除指定表，并重新创建该表

表的数据类型

数值类型

整型类型

  1. TINYINT – 1字节
  2. SMALLINT – 2字节
  3. MEDIUMINT – 3字节
  4. INT – 4字节
  5. BIGINT – 8字节

浮点数

  1. FLOAT
  2. DOUBLE
  3. DECIMAL – 需要指定精度(数字长度)和标度(小数位数)

字符串类型

字符串数据

  1. CHAR(存储的最大长度) – 10个位置只存储1个，其他用空格补位。性能高。
  2. VARCHAR(存储的最大长度) – 根据实际情况动态调整存储长度。性能较差。

二进制数据(音频、图片…)

  1. TINYBLOB
  2. BLOB
  3. MEDIUMBLOB
  4. LONGBLOB

文本数据

  1. TINYTEXT
  2. TEXT
  3. MEDIUMTEXT
  4. LONGTEXT

日期类型

  1. DATE – 日期值(年月日)
  2. TIME – 时间值(时分秒)
  3. YEAR – 年份值
  4. DATETIME – 混合日期和时间值
  5. TIMESTAMP – 混合日期和时间值、时间戳
