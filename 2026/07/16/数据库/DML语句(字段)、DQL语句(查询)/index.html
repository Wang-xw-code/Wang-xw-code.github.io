数据库

DML语句(字段)、DQL语句(查询)

DML语句 – 对数据库中表的数据记录进行增删改操作

插入数据操作 – 值是字符串或日期型数据需要包含在单引号之中

  1. INSERT INTO 表名 (字段1,字段2...) VALUES (值1,值2...); – 给指定字段添加数据
  2. INSER INTO 表名 VALUES (值1,值2...); – 给全部字段添加数据
  3. INSERT INTO 表名 VALUES (值1,值2...),(值1,值2...),(值1,值2...); – 给指定表批量添加数据

更新数据操作

  1. UPDATE 表名 SET 字段名1 = 值1,字段名2 = 值2,...[WHERE 条件] – 修改数据，如果没有条件，则会修改整张表的所有数据

删除数据操作

  1. DELETE FROM 表名 [WHERE 条件] – 删除数据，没有WHERE条件则会删除整个表的数据，且不能删除某一个字段的值(可以使用UPDATE)

DQL语句 – 用来查询数据库中表的记录

代码模板 – 编写顺序！！！

基本查询

  1. SELECT 字段1,字段2,字段3... FROM 表名; – 查询多个字段
  2. SELECT 字段1 [AS 别名1], 字段2 [AS 别名2] ... FROM 表名; – 设置别名
  3. SELECT DISTINGCT 字段列表 FROM 表名; – 去除重复记录

条件查询

  1. SELECT 字段列表 FROM 表名 WHERE 条件列表
  2. 常见条件

    1. – 大于

    2. = – 大于等于

    3. < – 小于
    4. <= – 小于等于
    5. <>或!= – 不等于
    6. BETWEEN … AND … – 在某个范围之内(包含边界值)
    7. IN(…) – 值在IN之内的符合某一个就行
    8. LIKE 占位符 – 模糊匹配(_匹配单个字符，%匹配任意个字符，比如__代表查找长度为二的字符数据，%x代表以x结尾的数据)
    9. IS NULL – 是NULL
    10. AND或&& – 并且
    11. OR或|| – 或者
    12. NOT或! – 非、不是

聚合函数查询 – 偏计算

  1. 聚合函数 – 将一列数据作为一个整体，进行纵向计算(所有的NULL值不参与计算)
    1. count – 统计数量
    2. max – 最大值
    3. min – 最小值
    4. avg – 平均值
    5. sum – 求和
  2. SELECT 聚合函数(字段列表) FROM 表名; – 根据函数查找数据

分组查询

  1. SELECT 字段列表 FROM 表名 [WHERE 条件] GROUP BY 分组字段名 [HAVING 分组后的过滤条件]; – WHERE在分组之前进行过滤，不满足WHERE条件则不参与分组；而HAVING是分组之后对结果进行过滤
    1. SELECT gender, count(*) FROM employee GROUP BY gender – 根据性别分组，统计男性员工和女性员工的数量
    2. SELECT worKaddress,count(*) FROM emp WHERE age < 45 GROUP BY workaddress HAVING count(*)>=3; – 查询年龄小于45的员工，并根据工作地址分组，获取员工数量大于等于3的工作地址
  2. 执行顺序
    WHERE > 聚合函数 > HAVING

排序查询

  1. SELECCT 字段列表 FROM 表名 ORDER BY 字段1 排序方式1, 字段2 排序方式2; – 如果是多字段排序，当第一个字段值相同时，才会根据第二个字段进行排序
  2. 排序方式
    1. ASC – 升序(默认)
    2. DECE – 降序

分页查询

  1. SELECT 字段列表 FROM 表名 LIMIT 起始索引,需要查询个数; – 浏览器中的第几页的这一整页的数据依此在数据库中查询，或者说从第几个查询到第几个
  2. tips
    1. 起始索引从0开始，起始索引=(查询页码数-1)*每页显示记录数
    2. 分页查询是数据库的方言，不同的数据库有不同的实现，MySQL中是LIMIT
    3. 如果查询的是第一页数据，起始索引可以省略，直接简写为LIMIT 10

DQL的执行顺序 – 了解就好，在简写as之中需要知道

FROM从哪个表查询 -> WHERE选取表中的哪些数据 -> GROUP BY进行分组查询 -> SELECT选取需要展示的字段 -> ORDER BY进行顺序的排序 -> LIMIT分页显示个数

SELECT name,age FROM emp e where e.age>15 order by age asc;
