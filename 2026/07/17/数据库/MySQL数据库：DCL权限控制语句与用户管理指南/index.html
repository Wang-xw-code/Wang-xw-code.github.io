MySQL数据库：DCL权限控制语句与用户管理指南

Created2026-07-17|Updated2026-07-22|数据库
|Post Views:

DCL语句

管理用户

  1. 查询用户
  1. CREATE USER '用户名'@'主机名' IDENTIFIED BY '密码'; – 创建用户，如果主机名为通配符‘@’，则任意主机都能通过该账户访问数据库
  2. ALTER USER '用户名'@'主机名' IDENTIFIED WITH mysql_native_password BY '新密码'; – 修改用户密码
  3. DROP USER '用户名'@'主机名'; – 删除用户

控制权限

  1. SHOW GRANTS FOR '用户名'@'主机名'; – 查询用户权限
  2. GRANT 权限列表 ON 数据库名,表名 TO '用户名'@'主机名'; – 授予用户权限
  3. REVOKE 权限列表 ON 数据库名,表名 FROM '用户名'@'主机名'; – 撤销用户权限
  4. 权限说明
    1. ALL – 所有权限
    2. SELECT – 查询数据权限
    3. INSERT – 插入数据权限
    4. UPDATE – 修改数据权限
    5. DELETE – 删除数据权限
    6. ALTER – 修改表权限
    7. DROP – 删除数据库/表/视图权限
    8. CERATE – 创建数据库/表权限
  5. tips
    1. 可以在数据库或表处使用通配符*代表所有的数据
    2. 多个权限之中使用逗号”,”分离
